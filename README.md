# CursedLands 中文汉化补丁（双语字幕）

适用于 **Winter Wolves** 发行的 **Steam 版** CursedLands 游戏。

> 注：本补丁仅针对 Winter Wolves 出品的 CursedLands，请勿与其他同名游戏混淆。

## 汉化范围

-  **已汉化**：角色剧情对白、菜单选项（双语字幕：英文在上、中文在下）
-  **未汉化**：战斗文本、武器/物品描述及其他系统文本

## 安装方法

把本压缩包内的 `game` 文件夹内容，解压合并到你电脑上的 CursedLands 游戏目录下的 `game` 文件夹里即可。

（即：让 `game/tl/chinese/`、`game/fonts/`、`game/zz_chinese.rpy` 出现在游戏 `game/` 目录下）

## 内容

- `game/tl/chinese/`    汉化翻译文件（剧情对白 + 菜单选项，双语：英文在上、中文在下）
- `game/fonts/`         中文字体（Noto Sans CJK SC，解决乱码）
- `game/zz_chinese.rpy` 配置文件（默认启用中文、字体接线、缩小对白字号）

## 说明

- 直接启动游戏即为中文双语；想切回英文可在游戏内 Preferences（设置）里改 Language。
- 本补丁需配合原版 CursedLands（Steam 版，Winter Wolves 发行）使用。
- 未汉化的战斗、武器描述等内容将保持英文原文。
